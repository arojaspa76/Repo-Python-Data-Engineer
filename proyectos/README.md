# Curso Ingeniería de Datos en Plataformas en la Nube y Data Warehousing con Python - Sesion 10 y 11

## Proyectos Finales

A continuación se presentan tres proyectos prácticos, cada uno diseñados para completarse en unas 6 horas, alineados con el objetivo del curso: entrenar a los estudiantes en el uso de Python para implementar pipelines de ingeniería de datos en la nube, usando herramientas de AWS, GCP y entornos multi-nube. Cada proyecto incluye el objetivo, las herramientas a utilizar, los pasos clave, datasets recomendados y entregables esperados. Están planteados a nivel intermedio, suponiendo conocimientos básicos de Python y conceptos de nube.
